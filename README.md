# Vento Leste Kite School

Site de uma escola de kitesurf fictícia em Cumbuco (CE). Projeto de portfólio.

Página única em HTML, CSS e JS puros, sem build. Tem painel de vento simulado, gráfico interativo da temporada e formulário de reserva de demonstração (nada é enviado nem guardado).

## Rodar localmente

Abra `index.html` no navegador.

## Publicar

Settings → Pages → Deploy from a branch → `main` / root.
